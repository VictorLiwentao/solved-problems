## Original problem

## Result

The certificates in all thirteen rows hold. The proofs use corner entries of permutation diagrams, descents of cycle words and a record-preservation identity.

Mao proposes the certificates and proves the record-preservation proposition used in the last two rows. This draft groups the table as a single contribution.

# Relative densities of abelian compression dictionaries

Wentao Li · Prepared with assistance from OpenAI Codex

Each deeper dictionary language has density zero in its predecessor. Partial enumeration of any positive-density core eventually identifies the target.

The proof compares two ways to write a vector’s coordinates in positional notation. Squaring the base groups successive digits and puts a higher cost on one digit in each pair. The resulting strict entropy gap makes the coarser language sparse inside the finer one.

**Original question.** Xiaoyu Li, Andi Han, Dai Shi, Zheng Gao, Jiaojiao Jiang and Junbin Gao (2026), §5, open problem 2. [Primary source](https://arxiv.org/abs/2606.14688v1)

**Significance estimate: 48/100.** An entropy gap answers a structural density question for this specific family of compression models.

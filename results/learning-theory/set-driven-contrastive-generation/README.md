# Removing order and repetition counts from contrastive generation

Wentao Li · Prepared with assistance from OpenAI Codex

Every successful generator on a countable contrastive class can use only the set of observed pairs. Finite witnesses indexed by admissible edge sets characterize success.

The learner reconstructs a virtual history from the observed pairs. Each time a hypothesis forces an error, the simulation must also cover one more of its positives. Infinitely many such errors would give a full presentation on which the original learner fails.

**Original question.** Xiaoyu Li, Andi Han, Jiaojiao Jiang and Junbin Gao (2026), Appendix D.3, order dependence. [Primary source](https://arxiv.org/abs/2605.06211v2)

**Significance estimate: 61/100.** Eliminates an entire information resource and yields a presentation-dependent witness criterion.

# How small can the privacy budget be for language identification?

Wentao Li · Prepared with assistance from OpenAI Codex

For any diverging sublinear target exponent $r(n)$, every countable class admits that identification rate exactly when $n\varepsilon_n/r(n)$ tends to infinity.

The upper bound chooses a slower-growing search horizon in the published private learner. The lower bound puts nearby distributions on the same rational thresholds. Privacy transfers the probability of predicting the wrong label between them, which rules out a positive exponent at the proposed boundary.

**Original question.** Xiaoyu Li, Andi Han, Jiaojiao Jiang and Junbin Gao (2026), Appendix H.1, question 3. [Primary source](https://arxiv.org/abs/2604.07238v2)

**Significance estimate: 66/100.** Closes a gap between two privacy scales for an entire family of statistical rates. The upper bound uses the published mechanism.

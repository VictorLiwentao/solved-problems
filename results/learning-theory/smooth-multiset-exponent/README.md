# The sharp separation exponent for smooth neural set encoders

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

On multisets of size at most n the optimal lower-Hölder exponent is n for Gaussian, tanh, sigmoid and softplus features on compact domains containing a line segment. The argument gives a finite upper exponent for deep smooth message passing.

**Original question.** Can matching upper bounds on the separation exponents of smooth sum aggregators be proved? [Davidson and Dym, 2024, Theorem 3.3 and Section 7, ICLR 2025](https://arxiv.org/abs/2406.06984)

**Scope and prior work.** Davidson and Dym prove the necessary exponent. Earlier finite-witness work establishes injectivity. The new upper bound applies to a stated real-analytic class, and the graph upper exponent may be loose.

**Significance estimate.** 66/100. It turns a necessary smoothness obstruction into a sharp rate for common activations and yields a deterministic finite feature bank on each compact domain.

**Review status.** Written argument. Independent proof and priority review are pending.

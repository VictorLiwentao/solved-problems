# The computational strength of robust contrastive tell-tales

Wentao Li · Prepared with assistance from OpenAI Codex

The halting oracle suffices to return completed robust tell-tales and can be necessary even with decidable finite-sample consistency.

**Original question.** Xiaoyu Li, Andi Han, Jiaojiao Jiang and Junbin Gao (2026), §8(v) and Appendix D.5. [Primary source](https://arxiv.org/abs/2605.06211v2)

**Significance estimate.** 56/100. It locates an exact computational obstruction for a witness required by a recent learning theorem.

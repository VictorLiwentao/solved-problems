# A test for representative generation with overlapping groups

Wentao Li · Prepared with assistance from OpenAI Codex

Convex hulls of fresh group-membership vectors characterize uniform and nonuniform representative generation with overlapping groups.

**Original question.** Charlotte Peale, Vinod Raman and Omer Reingold (2025), discussion of overlapping groups. [Primary source](https://proceedings.mlr.press/v267/peale25a.html) The manuscript credits the earlier formal counterexample for overlapping tail groups.

**Significance estimate.** 57/100. It extends the partition characterization to arbitrary countable group incidences.

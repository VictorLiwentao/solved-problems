# When vanishing noise permits a target-dependent mistake budget

Wentao Li · Prepared with assistance from OpenAI Codex

Countable classes admit a target-dependent mistake cap on every vanishing-noise stream exactly when all finite intersections of targets are infinite.

**Original question.** Jon Kleinberg, Charlotte Peale and Omer Reingold (2026), §7.1, bounded mistakes under vanishing noise. [Primary source](https://arxiv.org/abs/2605.10809)

**Significance estimate.** 47/100. It separates a uniform cap per target from merely having finitely many errors on each stream.

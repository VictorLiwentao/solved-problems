# Egorov ideals on arbitrary finite measure spaces

Wentao Li · Research draft with OpenAI Codex assistance · November 22, 2026

[Proof (PDF)](egorov-finite-measure-spaces.pdf) · [LaTeX source](egorov-finite-measure-spaces.tex) · [BibTeX](citation.bib)

Kwela's Theorem 3.4 eliminates the error parameter from the Egorov test on the Lebesgue unit interval. The paragraph preceding that theorem and Remark 6.10 ask about the corresponding test and Fubini-sum theorem for all finite measure spaces in the sense of Kadets and Leonov. Both extend. [Kwela, first posted 2023, Theorems 3.4 and 6.11](https://arxiv.org/abs/2312.00205) · [2024 journal article](https://doi.org/10.1016/j.topol.2024.109112) · [Kadets and Leonov, 2007](https://jmag.ilt.kharkiv.ua/index.php/jmag/article/view/jm03-0196e)

**The incidence test.** Let $I$ be an ideal on $\omega$ containing the finite sets. For measurable sets $E_j$ on a probability space let $a(x)=\{j:x\in E_j\}$. The universal Egorov property for $I$ says that on every probability space, whenever $a(x)\in I$ at each point, for every $\epsilon>0$ there is $C\in I$ with
$$\mu\{x:a(x)\subseteq C\}>1-\epsilon.$$
The event in braces is measurable for each fixed $C$. Finite measures reduce to probabilities by normalization, with a zero measure trivial. This is the set version of the Kadets–Leonov criterion. Indeed apply the function version to the indicators. Conversely apply the incidence test at the countably many thresholds $1/k$ to $|f_j-f|$, then intersect the good sets using exceptional measures summing to less than $\epsilon$. This gives ideal-uniform convergence on that intersection.

**One fixed fraction suffices.** Suppose on every probability space the test always gives a $C\in I$ covering at least half the mass. On the measurable residual space $\{x:a(x)\not\subseteq C\}$ apply the same assertion with the normalized restricted measure. After $k$ steps the residual measure is at most $2^{-k}$, and the finite union of the selected $C$ belongs to $I$. Its covered set contains all the points covered at any step. This yields arbitrary precision. Any fixed positive covered fraction works. It is the quantifier over all probability spaces that permits normalization on the residual space.

**Fubini sums.** Let $J$ be any ideal on $\omega$ and $I_i$ analytic ideals on $\omega$. Define $S$ on $\omega^2$ by $B\in S$ exactly when $\{i:B_i\notin I_i\}\in J$, where $B_i=\{j:(i,j)\in B\}$. Then $S$ has the universal Egorov property if and only if $J$ has it and $\{i:I_i\text{ fails it}\}\in J$.

For necessity of the first condition, encode a $J$-valued incidence map by assigning the whole row $\omega$ at its active indices and the empty row elsewhere. An $S$-bound gives a $J$-bound by taking its positive rows. For the second condition let $T$ be the set of bad indices, and assume $T\notin J$. By the fixed-fraction test, for each $i\in T$ there is a probability space and an $I_i$-valued incidence map $a_i$ for which every fixed $I_i$-bound covers less than half the probability. Take the countable product of the witnessing spaces and pull back each $a_i$ from its coordinate. Use empty rows elsewhere. The resulting array is pointwise $S$-small. For any $B\in S$, some $i\in T$ has $B_i\in I_i$. The measurable set covered by $B$ is contained in the cylinder on which $a_i\subseteq B_i$, so it has measure less than half. This contradicts the fixed-fraction test for $S$.

For sufficiency take an arbitrary pointwise $S$-small array $a_i(x)$, and let $T=\{i:I_i\text{ fails the property}\}\in J$. Work in the completion of the probability space. For every $i$, $a_i$ is measurable into Cantor space because all its coordinates are measurable. Analytic subsets of Cantor space are universally measurable. Pulling back a Borel sandwich for $I_i$ under the law of $a_i$ shows that $\{x:a_i(x)\in I_i\}$ belongs to the completion even if the original space has no regularity assumption. The bad-row map
$$x\longmapsto T\cup\{i:a_i(x)\notin I_i\}$$
is coordinatewise measurable and takes values in $J$. Use its Egorov property to find $D\in J$, enlarging $D$ to contain $T$, and a good set of mass greater than $1-\epsilon/2$ on which all bad rows lie in $D$. For each $i\notin D$, replace $a_i(x)$ by the empty set whenever it is not in $I_i$. Use the property of $I_i$ to bound this modified map by a fixed $B_i\in I_i$ off a set of mass less than $\epsilon 2^{-i-2}$. Set $B_i=\omega$ for $i\in D$. The array $B$ belongs to $S$ and covers the intersection of all the good sets, of mass greater than $1-\epsilon$. Coverage by the fixed $B$ is itself measurable on the original space, which proves the assertion there. The product formula follows by taking all row ideals equal.

**Comparison of the two definitions.** For every universally measurable ideal, testing the Lebesgue unit interval is sufficient. Given a pointwise ideal-valued incidence map on an arbitrary probability space, its law $\nu$ on Cantor space gives measure one to a Borel subset of $I$. Indeed every Borel subset of $I^c$ has zero measure, and $I^c$ is measurable in the completion of $\nu$. Realize $\nu$ as the law of a measurable map from the Lebesgue interval and replace values off that Borel subset by the empty set on a null event. A fixed $C\in I$ covering this map with probability $>1-\epsilon$ satisfies $\nu(\{A:A\subseteq C\})>1-\epsilon$. The original map is therefore covered with the same probability. The reverse implication is immediate. In particular this comparison covers all analytic row ideals above, while the Fubini-sum theorem permits an arbitrary outer ideal.

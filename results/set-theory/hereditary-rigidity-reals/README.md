# Hereditary rigidity on the real line

Wentao Li · Prepared with assistance from OpenAI Codex

[Proof (PDF)](hereditary-rigidity-reals.pdf) · [LaTeX](hereditary-rigidity-reals.tex) · [BibTeX](https://raw.githubusercontent.com/VictorLiwentao/solved-problems/main/results/set-theory/hereditary-rigidity-reals/citation.bib)

Consistently with ZF and dependent choice, every binary relation on the reals has a countable restriction with a shift automorphism. Hereditary rigidity can fail to pass from a set to its power set.

**Original question.** Paul Howard and Eleftherios Tachtsis, 2016. [§6, Problems 4 and 6](https://doi.org/10.4064/fm960-12-2015)

## Argument

Color each unordered pair by both directed incidences and both loop bits. In a model where all sets of reals have the Baire property, Galvin’s theorem produces a perfect homogeneous set. Shifting an ordered copy of the integers in it preserves the relation.

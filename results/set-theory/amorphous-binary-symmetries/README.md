# Finite symmetries of binary relations on amorphous sets

Wentao Li · Prepared with assistance from OpenAI Codex

[Proof (PDF)](amorphous-binary-symmetries.pdf) · [LaTeX](amorphous-binary-symmetries.tex) · [BibTeX](https://raw.githubusercontent.com/VictorLiwentao/solved-problems/main/results/set-theory/amorphous-binary-symmetries/citation.bib)

Every finite list of binary relations on an amorphous set has a common nonidentity involution of finite support, even after naming any finite set of points. Both rigidity principles in Problem 3 exclude amorphous sets.

**Original question.** Paul Howard and Eleftherios Tachtsis, 2016. [§6, Problem 3](https://doi.org/10.4064/fm960-12-2015)

## Argument

Complement each cofinite row and mark its index. After removing finitely many exceptional columns the underlying graph is locally finite. Amorphousness bounds its component sizes, so two finite components with the same colors can be interchanged.

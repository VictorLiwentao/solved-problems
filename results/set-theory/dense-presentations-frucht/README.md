# Dense presentations of the basic Fraenkel model

Wentao Li · Prepared with assistance from OpenAI Codex

[Proof (PDF)](dense-presentations-frucht.pdf) · [LaTeX](dense-presentations-frucht.tex) · [BibTeX](https://raw.githubusercontent.com/VictorLiwentao/solved-problems/main/results/set-theory/dense-presentations-frucht/citation.bib)

Frucht's theorem can fail in a permutation model even when the presenting group has no nonidentity internal permutation. The proposed converse holds for closed groups with finite supports.

**Original question.** Brian Pinsky, 2023. [§5, Conjecture 13 in the arXiv version](https://arxiv.org/abs/2305.11382v1)

## Argument

A dense free group of permutations presents exactly the same finite-support model as the full symmetric group. Internal permutations in the full presentation move only finitely many atoms. The free group is torsion-free, so none of its nonidentity elements survives this test. With a closed presenting group its finite-tuple orbits recover the group, yielding the positive converse.

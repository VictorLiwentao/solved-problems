# Projective type and self-surjections of power sets

Wentao Li · Prepared with assistance from OpenAI Codex

[Proof (PDF)](projective-amorphous-powers.pdf) · [LaTeX](projective-amorphous-powers.tex) · [BibTeX](https://raw.githubusercontent.com/VictorLiwentao/solved-problems/main/results/set-theory/projective-amorphous-powers/citation.bib)

For an amorphous set, some positive finite power of its power set admits a noninjective self-surjection exactly when the set is of projective type. In that case every positive finite power does.

**Original question.** Yifan Hu, Ruihuan Mao and Guozhen Shen, 2025. [§6, Questions 6.1 and 6.2, published in 2026](https://arxiv.org/abs/2510.13508)

## Argument

Encode one self-map by a countable language on the original set. If algebraic closure is degenerate, a countable model consists of equally sized finite blocks whose permutations preserve the structure. The finitely many patterns on a block give a uniform bound on every forward orbit. A surjection with that bound is injective.

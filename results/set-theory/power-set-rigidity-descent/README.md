# Rigidity need not descend from a power set

Wentao Li · Prepared with assistance from OpenAI Codex

[Proof (PDF)](power-set-rigidity-descent.pdf) · [LaTeX](power-set-rigidity-descent.tex) · [BibTeX](https://raw.githubusercontent.com/VictorLiwentao/solved-problems/main/results/set-theory/power-set-rigidity-descent/citation.bib)

Relative to the consistency of ZF, an amorphous set can have a rigid power set while every binary relation on the underlying set has a nontrivial automorphism.

**Original question.** Paul Howard and Eleftherios Tachtsis, 2016. [§6, Problem 7](https://doi.org/10.4064/fm960-12-2015)

## Argument

In the binary vector-space permutation model, the only internal linear automorphism is the identity. Directed membership edges identify the singletons, and loops on three-point lines force every permutation of the singletons to be linear. Jech–Sochor transfer yields a pure ZF example.

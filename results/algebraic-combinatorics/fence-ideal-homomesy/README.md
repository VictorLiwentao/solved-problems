# Unequal rowmotion averages on a uniform fence

Wentao Li · Research draft prepared with assistance from OpenAI Codex

[Proof (PDF)](fence-ideal-homomesy.pdf) · [LaTeX](fence-ideal-homomesy.tex) · [Citation](citation.bib) · [Exact check](verify.py)

## Original problem

On an odd number of equal fence segments, must order ideals have mean size equal to half the fence on each rowmotion orbit? [Sergi Elizalde, Matthew Plante, Tom Roby and Bruce E. Sagan, 2021](https://arxiv.org/abs/2108.12443) (Conjecture 6.4(b) in v1, later Conjecture 5.4(b)).

## Result

On a 32-element fence one 237-step orbit has total ideal size 3,774. The proposed half-size average would give 3,792.

The source proved the prediction for several short fences and checked small parameters. This result concerns the order-ideal assertion in part (b).

**Significance 53/100.** Disproves the order-ideal half-average conjecture for uniform odd fences. A single explicit orbit suffices. Independent proof and priority review is pending.

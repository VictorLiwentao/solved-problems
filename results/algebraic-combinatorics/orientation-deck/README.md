# Recognizing a tree from its orientation functions

Wentao Li · Research draft prepared with assistance from OpenAI Codex

[Proof (PDF)](orientation-deck.pdf) · [LaTeX](orientation-deck.tex) · [BibTeX](citation.bib)

## Original problem

Do nonisomorphic undirected trees give different multisets of chromatic quasisymmetric functions over all orientations? [Jean-Christophe Aval, Karimatou Djenabou and Peter R. W. McNamara, 2022](https://doi.org/10.5802/alco.273) (Question 5.5, numbered 5.1 in the first preprint).

## Result

Even the set of top ascent coefficients determines the undirected tree. Its rooted orientations can be recognized by counting how many vertices can simultaneously take the smallest color.

The original paper identifies the top ascent coefficient. The proof then uses Hasebe and Tsujie’s rooted-tree reconstruction theorem. [Original rooted-tree theorem](https://arxiv.org/abs/1610.03908)

**Significance 49/100.** Answers a published reconstruction question by reducing it to the established rooted-tree theorem. The input contains information from every orientation. Independent review of the proof and priority is pending.

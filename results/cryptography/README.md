# Cryptography

[All drafts, A–Z](../README.md) · [Scores and original questions](../../docs/scores-and-sources.md#cryptography)

These drafts study Boolean functions on inputs of fixed Hamming weight. Nonlinearity measures distance from affine functions. Corrector order measures cancellation of Walsh coefficients grouped by weight.

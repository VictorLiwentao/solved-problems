# Cryptography

[All drafts, A–Z](../README.md) · [Scores and original questions](../../docs/scores-and-sources.md#cryptography)

The protocol drafts cover private simultaneous messages, conditional disclosure of secrets, card-based secure computation and zero-knowledge proofs of proximity. The collection also covers network conditions for secure multiparty computation, arithmetic switches, garbled lookups and Boolean functions on inputs of fixed Hamming weight.

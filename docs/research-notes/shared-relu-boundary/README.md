# Closure of ReLU slope tuples with a shared hidden unit

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

For any number of blocks with one shared and one private unit per block, a tuple is in the closure precisely when it is realizable or all blocks belong to one tangent space of the rank-one cone.

**Original question.** What compatibility conditions describe the limits of multi-region slope matrices sharing a rank-one contribution? [Alexandr and Montúfar, 2025, Examples 37–38 and the multi-region question continued by Alexandr et al. in 2026](https://arxiv.org/abs/2508.03867)

**Scope and prior work.** The rank-one model and examples are due to Alexandr and Montúfar. The projective membership test describes the full point set of this family, including missing real limits.

**Significance estimate.** 56/100. It gives a full boundary test over the reals and complexes for one overlap pattern. The general overlap problem and proposed ideal generators remain open.

**Review status.** Written argument. Independent proof and priority review are pending.

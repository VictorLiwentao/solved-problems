# Escape times near regular deep linear completions

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

A projected entropy flow controls departures from regular completions. On the symmetric near-rank-one family the exit time has an explicit logarithmic dependence on the initialization in ordered limits.

**Original question.** How long does large-inverse-temperature training shadow a selected completion, and how does its exit time depend on initialization? [Treviño, 2026, Section 12.2](https://arxiv.org/abs/2610.05551)

**Scope and prior work.** The singular perturbation theorem is classical. The reduced field and the initialization-dependent time coefficient are specific to this model.

**Significance estimate.** 54/100. It gives a quantified exit time for a specified regular regime. Uniform joint limits near singular initializations and generic global metastability remain open.

# The ridge transition in entropic diagonal completion

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

All global minimizers have equal singular values. An explicit threshold separates a unique scalar matrix from a family of scaled orthogonal matrices with prescribed diagonal.

**Original question.** Which full-rank matrices attain the confined variational problem for the proposed quadratic ridge penalty? [Treviño, 2026, Section 12.6, proposed ridge model](https://arxiv.org/abs/2610.05551)

**Scope and prior work.** The source establishes confinement and notes that a ridge term alone does not furnish a corank-one barrier. This note uses the special diagonal data to identify the minimizers.

**Significance estimate.** 50/100. It gives an exact attainment and selection result for the stated model. General sensing masks do not have this radial reduction.

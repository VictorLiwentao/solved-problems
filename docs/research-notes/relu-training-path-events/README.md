# When the facets of a ReLU network change during training

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

Over a compact time interval, generic smooth paths have finitely many changes. Every semialgebraic or analytic-through-the-endpoints path does too. An explicit determinant list bounds events on polynomial paths and tracks the vertices.

**Original question.** Does the facet structure of a network change at only finitely many places along a general training path? [Masden, 2022, Section 6, training-path conjecture](https://arxiv.org/abs/2207.07696)

**Scope and prior work.** Finite stratification and transversality supply the qualitative conclusion. The construction gives sign tests and vertex formulas, with a coarse bound. Nonoscillation for a specified gradient training differential equation remains open here.

**Significance estimate.** 55/100. This specifies what generality the conjecture needs and gives a computable event bound. An explicit smooth path has infinitely many changes.

**Review status.** Written argument. Independent proof and priority review are pending.

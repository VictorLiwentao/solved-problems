# Long-time behavior and stationary thresholds for normalized noisy attention

Wentao Li · Prepared with assistance from OpenAI Codex · November 2026

Repulsive row-normalized attention converges to uniform at every positive diffusivity. Attractive attention converges at high diffusion and has a sharp threshold for a stationary variational problem.

**Original question.** How does diffusion affect the long-time behavior of spherical attention? [Geshkovski et al., 2023, Problem 7, diffusive transformer dynamics](https://arxiv.org/abs/2312.10794)

**Scope and prior work.** Mun and Rosenzweig previously obtained a sharp phase diagram for the unnormalized model. The row-normalized stationary equation uses a different variational quotient. The estimates treat spherical Brownian mean-field diffusion.

**Significance estimate.** 69/100. It gives a global convergence law for one sign and a sharp equilibrium threshold for the other. General attractive long-time dynamics remain open.

**Review status.** Written argument. Independent proof and priority review are pending.
